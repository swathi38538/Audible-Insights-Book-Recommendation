# Audible Insights: Intelligent Book Recommendations

## Project Overview
Audible Insights is an intelligent book recommendation system developed using Python, Machine Learning, NLP, and Streamlit.

The project analyzes Audible book data and recommends books based on genres, descriptions, and similarity.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib, Seaborn and Plotly
- Scikit-learn
- NLP and TF-IDF
- K-Means Clustering
- Streamlit

## Project Features
1. Data Preparation and Cleaning
2. Exploratory Data Analysis
3. NLP-based Book Similarity Analysis
4. K-Means Clustering
5. Content-Based Recommendations
6. Clustering-Based Recommendations
7. Hybrid Recommendation System
8. Interactive Streamlit Dashboard
